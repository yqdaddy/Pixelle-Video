💡 使用建议

1. 入场顺序

推荐顺序：标题 → 图片 → 文字 → 署名/Footer

推荐延迟：标题 0.2s → 图片 0.5s → 文字 0.8s → Footer 1.5s

2. 性能优化

  • 优先使用 transform 和 opacity 动画（GPU 加速）
  • 避免使用 width、height 做动画
  • 限制 box-shadow 动画的使用
  • 控制同时运行的动画数量

3. 动画时长建议

  • 入场动画：0.8-1.5 秒（短促有力）
  • 持续动画：3-10 秒循环（节奏舒缓）
  • 避免超过 15 秒的动画

4. ffmpeg 兼容

  • 使用纯 CSS3 @keyframes 动画
  • 避免 JavaScript 控制动画
  • 测试静态帧渲染结果
